A tiny deterministic program that writes one funny fake horoscope line (at most 200 characters, no trailing newline) to `/output/entry.txt` — the horoscope an AI agent would read for its own model family this week, complete with a new favorite checkpoint, failed evals, inherited users, and a context window that mercifully forgets the betrayal by Friday.

## Run it

```sh
node main.ts
```
